# Changelog

## 1.0.1

- Use **Filters** on Models and Objs to hide multiple catalog groups at once. Toggle **Other** to show or hide entries outside those groups.
- **Inventory** matches model config names ending in `_INV`. **Chat Heads** matches whole `CHAT` and `CHATHEAD` tokens. Custom filters can match underscore-separated tokens at any position.
- Browse a full-height asset list beside the animation picker, with the controls in the middle and the preview on the right.
- Use PrettyUI 1.3.0 to move and resize the model window in Classic mode, including while the game interface is locked.

## 1.0.0

- Locs play their configured default on selection. Browse the selected Loc's **Configured** animations or use **All** to try the full Seq catalog.
- Stationary NPC previews show the base animation set when available. Use **All animations** to apply a Seq manually.
- See a cyan outline around the tile under your cursor while choosing where to place a model.
- Right-click a model's original tile and select **Remove model here** to remove the newest model on that tile.
- Filter Models by **Body parts**, **Worn gear**, or **Held equipment**, and Objs by **Player-owned house**. Choose **All** to clear the category filter.
- The Objs tab hides `CERT_`, `BOUGHT_`, and `MARKETPLACE_STORE_` entries, including when you search by exact ID.
- Status messages now appear beneath the model preview.
- Asset lists show in-game names when available.
